# Rick and Morty Characters App

This is a frontend application developed as part of the .NET Angular technical test for Unosquare.  
It consumes the [Rick and Morty API](https://rickandmortyapi.com/api/character) and displays a list of characters using Angular standalone components.

## Features

- Character listing with image, name, status and species
- Pagination with "Previous Page" and "Next Page" buttons
- Angular 17 standalone components
- Bootstrap styling (responsive cards)

## Technologies

- Angular CLI 17.3.3
- TypeScript
- Bootstrap 4
- Rick and Morty public API

## Installation & Run Locally

```bash
# Clone the repository
git clone https://github.com/your-username/Rick-and-Morty-Angular.git
cd Rick-and-Morty-Angular

# Install dependencies
npm install

# Run the project
set NG_CLI_ANALYTICS=disabled && npm start
